Muchos sistemas distinguen más estados que éxito o fracaso. Conceptualmente pueden modelarse como éxito pleno, éxito con coste, resultado mixto, fracaso con consecuencia o imposibilidad.

El significado exacto de cada grado pertenece al sistema activo. El cerebro solo aporta el concepto general; el pack de sistema o el manual determina cómo se calcula y qué efectos tiene.

Un resultado fallido no debe convertirse automáticamente en ausencia de ficción. Si el sistema permite avanzar con complicaciones, el fallo puede producir coste, peligro, pérdida de posición, información incompleta o una nueva decisión.
